# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good intent, and keep discussions about the game. Harassment, insults, discrimination and spam are not tolerated, in issues, pull requests or anywhere else in this project's spaces.

## Enforcement

Report unacceptable behavior to the maintainer, [@leesujae17](https://github.com/leesujae17). Reports are handled privately. The maintainer may edit or remove comments, lock threads and block contributors who don't follow this code.
